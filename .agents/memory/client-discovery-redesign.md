---
name: Client discovery redesign
description: User-approved design constraint for BizIci client discovery.
---

Keep the native map as a primary discovery view when extending the approved warmer client UI; a nearby list is a complementary way to browse, not a replacement for the map.

**Why:** The user explicitly checked that the map would remain before approving implementation of the redesign, especially for the BizIci client.

**How to apply:** Preserve map availability, real location, markers, filters, and shop navigation during future discovery-screen changes, even when a list-first visual mockup is used as a reference.
